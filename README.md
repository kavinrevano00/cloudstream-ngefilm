# Ngefilm CloudStream Repository

Repository template untuk plugin CloudStream pribadi.

Base URL:
https://new39.ngefilm.site/

## Catatan
Provider di dalam template ini hanya merupakan kerangka pengembangan. Implementasikan parser/search/loadLinks hanya untuk konten dan stream yang Anda miliki atau berhak distribusikan.

## Build
Windows:
`gradlew.bat NgefilmProvider:make`

Linux/macOS:
`./gradlew NgefilmProvider:make`
